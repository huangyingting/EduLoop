# Internationalization

EduLoop's interface is available in Simplified Chinese (`zh-CN`, the default) and English (`en`). Question content has its own translation layer (see [Question content](#question-content)); subject, grade, and topic names stay in the catalog's default language.

## How the locale is chosen

- The learner picks a language with the switcher in the sidebar or on the sign-in and recovery pages. The choice is stored in the `eduloop-locale` cookie for one year.
- Without the cookie, everyone sees `zh-CN`. The app does not guess from `Accept-Language`, so existing learners see no change.
- The root layout reads the cookie, sets `<html lang>`, and passes only the active catalog to the browser. Reading the cookie makes every page render per request.

## Catalogs

- `src/i18n/messages/zh-CN.ts` is the source catalog and defines every key. `en.ts` is typed against it, so a missing or extra key fails `npm run typecheck`. `src/i18n/i18n.test.ts` also checks that every translation keeps the source's placeholders.
- Messages use `{name}` for parameters. `{count|one|other}` picks a singular or plural word for languages that need it, for example `"{count} {count|question|questions}"`.
- Server components call `getTranslator()` from `src/i18n/server.ts`. Client components call `useT()` or `useI18n()` (which also returns the locale for `Intl` formatting) from `src/i18n/client.tsx`.
- Keys built from data, such as badge slugs, go through `translateOr(t, key, storedText)` so unknown values fall back to the stored text.
- Default-locale strings used on the server (`QUESTION_TYPE_LABELS`, badge names written by the seed, and the install manifest) are read from the `zh-CN` catalog, so each string is defined once.

## API errors

API responses keep a stable `code`. Errors a learner can act on also return a `messageKey` from the `errors` namespace, built with `apiMessageError(key, status, code)`; the `error` text is developer-facing English. `describeApiError(error, fallback, t)` shows, in order: the network or rate-limit message, the catalog text for `messageKey`, the expired-session message for other 401s, and otherwise the caller's feature-specific fallback.

Authentication failures from Auth.js (`?error=` on the sign-in page) map to keys in the `authErrors` namespace through `authErrorMessage(t, error, code, context)`.

## Lint gate

ESLint rejects CJK string literals, template text, and JSX text in `src/components/` and `src/app/`. Add the text to both catalogs and render it with `t()`. The gate exempts:

- the content studio (`src/components/studio/`, `content-studio.tsx`, `learning-health-panel.tsx`, `src/app/studio/`), an operator tool that remains Chinese-only;
- the legal pages (`src/app/terms/`, `src/app/privacy-policy/`), which are authoritative in Chinese only. Other locales show a notice saying so.

## Emails

Email copy lives in `src/i18n/emails/`, separate from the UI catalogs so it is never sent to the browser. Emails triggered by a request (verification, password reset, email change, and security notices) use that request's interface language. Signed-in learners who switch language also store it on their account (`PUT /api/auth/locale`, `User.locale`), and reminders and weekly summaries use the stored value. Registration stores the language chosen before signing up.

## Question content

Archives for a collection in another language (today `data/en/amc*.json`) are imported by `npm run db:seed` as `QuestionTranslation` rows keyed by the same stable question IDs ([ADR 0008](adr/0008-translated-question-content.md)). A translation is imported only when its option labels match the stored question; the answer key, grading, assets, and tags always come from the stored question. English hints are derived from the English solutions.

In English, practice draws from translated questions first and falls back to Chinese questions when none match the filters; the player then says the question is only available in Chinese. Contest papers and results, the question bank, review lists, progress, hints, and post-answer explanations show the translation when one exists. `npm run seed:verify` checks the number of English translations (<!-- stat:seed.englishTranslations -->2,984<!-- /stat -->).

## Not yet localized

- Subject, grade, and topic names, and question content outside the AMC collection, are Chinese only.
